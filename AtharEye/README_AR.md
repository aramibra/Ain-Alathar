# AtharEye V14 — عين الأثر

نسخة احترافية ثنائية اللغة لنظام متابعة المواقع التراثية وتقييم المخاطر.

## التشغيل

1. انسخ مجلد `AtharEye` إلى `C:\xampp\htdocs\AtharEye`.
2. شغّل Apache وMySQL من XAMPP.
3. افتح `http://localhost/AtharEye/install.php`.
4. اختر **تثبيت أو ترقية المشروع بأمان**.
5. افتح `http://localhost/AtharEye/`.

> الترقية الآمنة تحفظ جداول وبيانات عين الأثر الحالية وتضيف الأعمدة الجديدة فقط. خيار إعادة الإنشاء يحذف جداول `ae_` ويعيد البيانات التجريبية.

## حسابات التجربة

- المسؤول: `admin@heritage.gov.sa` / `admin123`
- العالم الأثري: `archaeologist@heritage.gov.sa` / `archaeologist123`
- المستخدم: `user@heritage.gov.sa` / `user123`

## أهم التحسينات

- صفحة تقارير وإحصائيات احترافية مع توزيع الخطورة، المدن، الفلاتر، وتصدير CSV.
- صفحة **حول النظام** تشمل الرؤية والرسالة والأهداف والسياسات ودورة العمل.
- ملف شخصي لكل دور مع تحديث الاسم والبريد والهاتف واللغة وكلمة المرور.
- دعم العربية والإنجليزية من الهيدر، مع حفظ اللغة المفضلة في الحساب.
- إضافة وتعديل المواقع داخل نافذة منبثقة سلسة.
- تأكيد حذف احترافي داخل المشروع يعمل دون اعتماد على مكتبة خارجية.
- فوتر رئيسي غني بالهوية البصرية، مستوحى من بنية الفوتر المرجعي المرفق مع تكييفه لمشروع عين الأثر.
- هوية بصرية موحدة: الأخضر التراثي، الذهبي الهادئ، الأبيض، والخلفيات الفاتحة.
- ترقية قاعدة البيانات من V13 إلى V14 دون حذف البيانات.

## قاعدة البيانات

اسم القاعدة: `tabuk_heritage`

جداول النظام تبدأ بالبادئة `ae_` لمنع التعارض مع جداول المشروع الأصلية.
